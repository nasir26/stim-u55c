# build/

v++ build flow: `Makefile` (targets `sw_emu`, `hw_emu`, `hw`, `test`,
`bench`, `clean`), `connectivity.cfg`, `xrt.ini`.

`connectivity.cfg` (HBM bank assignment) and `xrt.ini` are real v++/XRT
build artifacts, needed once there's a v++ kernel wrapper and a host
runtime to configure -- that's `host/`, which lands in Phase 4. Per the
project brief, `connectivity.cfg` will be generated by a host-side
script rather than handwritten, so bank counts stay a single variable to
tune; nothing to generate yet.

`test` is real today: it runs everything pytest covers, which as of
Phase 2 includes the kernel's own C-sim testbenches (built with plain
g++, no Vitis needed) alongside the soft-model-vs-Stim suite -- same
thing CI runs.

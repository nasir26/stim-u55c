# build/

v++ build flow: `Makefile` (targets `sw_emu`, `hw_emu`, `hw`, `test`,
`bench`, `clean`), `connectivity.cfg`, `xrt.ini`.

Per the project brief, `connectivity.cfg` (HBM bank assignment) is
generated by a host-side script, not handwritten, so bank counts stay a
single variable to tune. That generator, and `xrt.ini`, land in Phase 2
alongside the kernel they configure -- nothing to generate yet.

`test` is the one target that's real today; it runs the CPU-only
soft-model-vs-Stim suite (same one CI runs).
